# Ecommerce-Sales-Analysis-Dashboard-Excel
Interactive E-commerce Sales Analysis Dashboard built using Microsoft Excel. Analyzes sales performance, customer demographics, product categories, monthly trends, order status, and sales channels using Pivot Tables, Charts, and Slicers to generate meaningful business insights.
This project is an interactive **E-commerce Sales Analysis Dashboard** created using Microsoft Excel. It focuses on analyzing sales data to identify business trends, customer purchasing behaviour, and product performance.

The dashboard provides insights into:

- **Sales Performance:** Analysis of total revenue and quantity sold.
- **Monthly Trends:** Tracking monthly sales performance and order patterns.
- **Customer Demographics:** Understanding purchasing behaviour based on gender and age groups.
- **Order Status:** Analyzing delivered, cancelled, returned, and other order statuses.
- **Sales Channels:** Comparing sales across platforms such as Amazon, Flipkart, Myntra, Ajio, and others.
- **Product Categories:** Identifying top-performing product categories.
- **Geographical Analysis:** Exploring sales distribution across different Indian states.

**Tools & Techniques Used:**
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Slicers and Interactive Filters
- Data Analysis and Visualization
- Dashboard Design

**Project Objective:**

To transform raw sales data into meaningful business insights through an interactive dashboard that supports better decision-making and helps identify sales trends, customer preferences, and growth opportunities.

This project demonstrates my practical skills in Excel, data analysis, and business intelligence.
